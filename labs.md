# А №30 я бы сделал особенной

Это уже не обычная лабораторная.

Пользователю дают условие:

> **Ты получил свой домашний сервер. Организуй на нём инфраструктуру для своей квартиры.**

Например, необходимо:

```text
                 HOME NETWORK
                      │
               ┌──────▼──────┐
               │   HOMELAB   │
               │             │
               │ SSH         │
               │ Web         │
               │ Docker      │
               │ NAS         │
               │ Backup      │
               │ VPN         │
               └─────────────┘
```

Он должен самостоятельно:

* создать пользователей;
* настроить права;
* открыть необходимые порты;
* запустить Docker;
* развернуть несколько сервисов;
* создать хранилище;
* настроить backup;
* обеспечить удалённый доступ;
* проверить безопасность.

И сайт уже не говорит ему каждую команду.

Он проверяет результат.

Например:

```text
FINAL HOMELAB
────────────────────────

✓ SSH configured
✓ SSH keys configured
✓ Users configured
✓ Firewall configured
✓ Docker configured
✓ Web server running
✓ Storage configured
✓ Backup configured
✓ HTTPS configured
✓ VPN configured

         10 / 10

       🏆
  HOMELAB BUILDER
```
